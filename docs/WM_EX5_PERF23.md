# WePlay 威马 EX5 perf23

正式 APP 名称改为 WePlay，采用用户在实车比较后选定的第 5 款图标：银色五竖条与青绿色播放弧线，背景透明。
使用原始选定图案，等比例导出 Android 五档密度 PNG。

版本代码 67，版本名 `0.2.17-legacy.1-wm-ex5-perf23-weplay`。
包名 `com.shihab.diplay.wmex5`，延用相同签名，可覆盖安装并保留配置。

本次只调整 APP 名称与桌面图标。音频仍使用 perf22 的稳定处理，默认缓冲 300 毫秒。
CarPlay 连接、双屏投屏、麦克风和其他默认设置延用 perf22。
今天下午的无线断线诊断记录单独保存；本包不包含未经实车验证的连接协议改动。
