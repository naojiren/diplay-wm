# WePlay perf25：威马实体左右键切歌

基于 perf24，沿用当前音频、麦克风、断线处理、双屏适配、图标和设置。

- CarPlay 主页面前台时自动订阅原厂 `Service.Input` 的上一首/下一首事件。
- 实体左键对应上一首（88），右键对应下一首（87）。威马服务只发送松开事件；直接转换成 iPhone 的 CarPlay 媒体 HID 指令，不转换成界面方向键。
- Android 媒体会话与原厂回调若收到同一次按键，通过该次按键的身份去重；不按固定时间屏蔽快速连续点击。
- 返回桌面或其他页面时注销专用监听，让现有桌面处理按键。CarPlay 设置/等待页面不发送切歌指令。
- 仅启用在威马安装包和 Android 6（API 23），核对原厂服务描述符。没有新增权限、全局按键注入或常驻后台服务。

原理来自用户指定的“评估桌面应用改造方案”聊天（01a12288-b683-7311-82dc-10ed11761a17）及 wm21 的实车记录，桌面左右键已由用户确认有效。接口实现不包含原厂 APK、SDK 二进制或车辆控制命令。

测试重点：CarPlay 内播放音乐，左右各按一次、快速连续按、长按、暂停后切歌；返回桌面后仍由桌面接收按键。曲目是否切换还取决于 iPhone 播放器和播放列表。单元检查不能代替这台车的新包实测。
