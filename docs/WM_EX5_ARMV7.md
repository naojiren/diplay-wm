# perf18 ARMv7 精简版

为 2019 款威马 EX5 / Android 6.0.1 / TI DRA74x 32 位系统精简打包，仅包含 `armeabi-v7a`。移除 ARM64、x86、x86_64 底层库，保留全部六个原版 ARMv7 库，重新对齐并使用原密钥签名。未删除界面、语言、双屏、音频、USB、无线或低延迟处理。

- 包体积：15.62 MB → **12.54 MB**，减少 19.73%（十进制 MB）。
- 对比原版 APK，六个 ARMv7 库、应用代码、资源、清单和认证输入的内容逐文件一致；APK 签名与原版一致。
- 公开源码的 ARMv7 构建同样通过完整检查，其应用代码、界面资源、清单和认证输入与最终精简包一致。两份素材声明仅存在换行格式差异，最终包保留原版声明。直接保留原版底层库避免了重新编译造成的路径及调试信息差异。
- 包名 `com.shihab.diplay.wmex5`、版本代码 62、版本名称与 perf18 相同，可覆盖安装；已有设置和开机自启开关保留。没有新增一次性默认值迁移。
- Ubuntu 完整检查通过：2,115 项测试，三个应用 lint 无错误；APK 签名验证覆盖 API 19–23，认证签名与篡改拒绝检查通过。
- 没有连接 ADB，没有进行新的实车测试。移除未使用架构主要节省下载和存储，不承诺减少卡顿或运行时内存。

安装附件：`DiPlay-WM-EX5-perf18-armv7.apk`。原始四架构包保留在 [原 perf18 Release](https://github.com/naojiren/diplay-wm/releases/tag/v0.2.17-wm-perf18)。默认源码构建同样只包含 ARMv7；模拟器开发可用 `-PwmUniversalAbis=true`。
